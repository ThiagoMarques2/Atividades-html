a tag <hr> insere uma linha horizontal para separar seções ou 
tópicos, melhorando a organização e legibilidade do conteúdo.

4. descreva o funcionamento dos comentários em html utilizando
a tag <!-- --> e sua importância para a manutenção do código 

Em HTML, <!-- --> cria comentários invisíveis, usados para
 explicações ou lembretes, facilitando a manutenção e 
compreensão do código

5. diferencie listas ordenadas e não ordenadas em html destacando
as tags <ol> e <ul>


Em HTML:

<ol> (lista ordenada) → itens numerados ou com sequência lógica.

<ul> (lista não ordenada) → itens marcados com bolinhas ou
 símbolos, sem ordem específica.

Resumo: <ol> organiza itens com ordem, <ul> organiza itens 
sem ordem, ambos usando <li> para cada elemento da lista.
